# Local configuration

This directory contains account-specific files that must stay private and are excluded from Git.

- Copy `.env.example` to `.env` and add your Gemini and TikTok credentials.
- Create `client_secret.json` from your own Google OAuth client for YouTube access.
- `token.json` and `tiktok_token.json` are created after each account is authorized.
- `historico_otimizacao.json` stores local channel activity and should remain private.
