# Agente YouTube Elite

Desktop application for analyzing, optimizing, and publishing YouTube content, with optional TikTok publishing support.

## Features

- Channel dashboard and audit
- Trend discovery
- Video optimization and publishing workflow
- Gemini-assisted analysis
- YouTube OAuth integration
- Optional TikTok integration

## Local setup

1. Create and activate a Python virtual environment.
2. Install the project dependencies listed in `requirements.txt`.
3. Copy `config/.env.example` to `config/.env` and add your own credentials.
4. Create `config/client_secret.json` using your own Google OAuth client.
5. Run `src/app_gui.py` from the project environment.

Credentials, OAuth tokens, channel history, build files, and local environments are intentionally excluded from this repository. See `config/README.md` for details.
